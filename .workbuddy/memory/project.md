# 基金买入工作台 — 项目系统提示词

> 本文件为本项目的系统提示词，应在本项目每次任务开始前被读取并遵守。

## 必做：任务开始前先读交接文档

每次开始本项目的任何任务之前，必须先阅读本项目根目录下的 `交接文档.md`：

- 路径：`D:\AI-projects\WorkBuddy\基金买入工作台\交接文档.md`
- 引用写法：`@交接文档.md`

阅读重点（尤其改动代码前务必理解）：

1. **项目定位与技术形态**：本地 Web 应用、Node 内置模块、单文件内联 HTML、零外部依赖、天天基金数据源。
2. **功能范围与关键流程**：启动流程、数据读写、净值获取、前端分层架构（`refreshAll()` 统一调度、渲染函数互不调用、调用链无环）。
3. **核心算法**：净值匹配、分红修正、份额法盈亏、区间/成立以来最大回撤、移动平均——口径约定为「涨跌幅与盈亏含分红，份额按单位净值折算，均线与回撤用单位净值口径」。
4. **验收标准**：五套测试（smoke-check / server-test / runtime-verify / edge-test / hover-test，共 324 项）必须全绿后才能交付。
5. **维护约束**：新增功能保持单文件全内联、零外部依赖、图表手写 SVG；新增/修改 API 时同步更新 `.smoke/server-test.js` 契约断言。

只有在理解上述内容后，再开始执行任务。涉及改 `public/index.html`、`server.js` 或新增/修改接口时，必须遵循文档约束，并在交付前跑通五套测试。
